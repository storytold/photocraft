# Hue/Saturation Photoshop live parity

This isolated test package compares PhotoCraft's current CLI against a running Photoshop through PS Generator Bridge. It is test code only; the PhotoCraft product remains Rust. The original issue PSD and synthetic RGB/8 swatches are checked with zero tolerance for visible RGB and full-canvas Alpha. The live tests also validate imported adjustment parameters, clipping, Photoshop pixel impact, reference stability, and cleanup of test-owned documents.

Install from this directory with `pnpm install --frozen-lockfile --registry https://mirrors.tencent.com/npm/`. Run `pnpm test:offline` for comparator tests. These do not run Photoshop.

Set `PHOTOCRAFT_HS_ISSUE_ROOT` to the external `hue-saturation-rgb-mismatch` issue folder and `PHOTOCRAFT_CLI` to the exact built CLI. Set `PHOTOCRAFT_ENGINE_SOURCE` when the CLI came from another checkout. A matching `PHOTOCRAFT_ENGINE_BUILD_INFO` can verify the binary's source; absent that, the recorded provenance is `BINARY_HASH_ONLY`. Use `PHOTOCRAFT_HS_CASES` with a comma-separated list of case IDs to opt into diagnostic swatches and isolated slider cases. An unset case selector runs the original issue case only. `PHOTOCRAFT_HS_ARTIFACTS` overrides the default ignored `artifacts/<run-id>` output directory.

Run the real test from this directory with `pnpm exec ps-generator-bridge test live --port <free-port>`. Photoshop must already be running with its Generator remote connection enabled and the bridge toolkit initialized. The official toolkit owns and cleans its temporary Generator child. An ordinary Vitest run skips the live declarations and does not count as Photoshop acceptance.

For broader diagnosis, set `PHOTOCRAFT_HS_CASES` to a comma-separated list such as `issue-original,swatches-combined,swatches-hue-only,swatches-saturation-only,swatches-lightness-only,gray-256-combined,gray-256-identity,image-hue-only,image-saturation-only,sectors-hue-minus157,sectors-hue-plus40`. The other available IDs are defined in `src/cases.js`. Every selected case remains a strict assertion. The sector ramps cover all six RGB hue sectors, with the middle channel from 0 to 255 and primary/secondary ties at the ends. The full-image slider cases start from a test-owned copy of the original PSD, remove its adjustment in that copy, verify the unadjusted import, then create the isolated adjustment. Diagnostic failures are reported separately from the original issue case.

The test copies every source to a unique per-case file, records the pre-existing Photoshop document set and active document, and closes only documents it opened. Each run keeps `provenance.json`, input PSD, Photoshop and PhotoCraft PNGs, a difference image, readback, and per-case `case.json`. A failed parity assertion still attempts cleanup and preserves evidence. The strict comparator ignores RGB only where both Alpha values are zero.
