# Actions editor screenshots

Original PhotoCraft UI captures rendered with the offscreen `snapshot` example at
1440 × 900, scale 1, with a synthetic gray document and two recorded actions.

- `classic-before.png`: the Classic Actions panel.
- `modern-after.png`: the modern Actions list with a group and action metadata.
- `editor.png`: the action editor and its recording, playback, and step controls.
- `icon-color-picker.png`: the action icon and color choices.

The captures use the dark appearance and CPU document canvas. The UI and original
synthetic content are licensed under MIT OR Apache-2.0, like PhotoCraft.
