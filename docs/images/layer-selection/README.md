# Saved layer selection (#10195)

Original synthetic artwork generated by
`crates/engine/examples/layer_selection_fixtures.rs`, rendered in PhotoCraft with its offscreen
`snapshot` example. No external artwork, personal photos or font files are included here.
The screenshots and generated artwork are licensed MIT OR Apache-2.0 (adjacent licenses).

Both captures open the same `single-third.psd`, which saves Layer 3 as the primary and only
selected layer. `before.png` uses base revision
`0379569d00341f0c2bef26f2d928db468b0f613f` and selects Layer 5. `after.png` uses this change
and restores Layer 3. The canvas pixels are unchanged.

Generate the input:

```sh
cargo run -p photocraft-engine --example layer_selection_fixtures -- /tmp/layer-selection
```

Run the capture on each revision, retaining the same generated input:

```sh
CRAFT_FONTS_DIR=/path/to/craft-fonts CRAFT_FONTS_REQUIRED=1 \
cargo run --profile test -p photocraft-ui-egui --example snapshot -- \
  --size 1440x900 --scale 1 --safe-gpu \
  --open /tmp/layer-selection/single-third.psd --out /tmp/selection.png
```

Captures use the CI font pin `b076417b5880bd4154bd22f00695b1d28c6bea83` and Mesa's software
Vulkan adapter for the egui renderer. `--safe-gpu` selects the CPU canvas. These captures verify
PhotoCraft's reopened Layers panel; they do not establish Photoshop interoperability.
