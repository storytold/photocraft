# ORBIT-07 field robot

An original sample model for PhotoCraft's optional 3D / UV workspace. The OBJ
contains 3,104 vertices and 5,996 triangles, with one material and a 2048 × 2048
color atlas. The MTL also binds roughness, metallic and emissive maps.

## Import

1. Extract the `orbit-07-demo.zip` package, or use the files in this folder.
2. In PhotoCraft, choose **3D**, then **File → 3D Import → Import Model**.
3. Open `orbit07.obj`. Keep `orbit07.mtl` and the PNG maps beside it.

The ZIP contains this README, the license notice, OBJ, MTL and four texture maps.
It does not include screenshots. The original model and maps are dedicated to
the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/);
see [`LICENSE.txt`](LICENSE.txt).
