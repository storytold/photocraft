## Paint a selection

This draft describes the proposed Selection Brush Tool and is not published for a released version.

1. Choose **Selection Brush Tool** in the W tool group.
2. Set **Size**, **Hardness**, and **Opacity** in the options bar.
3. Paint over the area to select. The coloured overlay shows the selection.
4. Choose **Subtract**, or hold Alt before starting a stroke, to remove selected areas.
5. To fill a loop, leave **Fill Closed Strokes** enabled and finish near the starting point.

Open **Overlay** to choose a colour, such as magenta, or change **Display Opacity**.
Display Opacity changes how the selection looks. Opacity changes how strongly it selects.
Switch to another selection tool to see the usual moving outline. Undo reverses one stroke.
